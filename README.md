# 김완진 | 웹 개발 포트폴리오

인터엠에서 PHP와 JavaScript로 오디오 장치 관리 웹 시스템을 개발했습니다. 인터엠향·한화향 ISLS 프로젝트의 화면 개발, 장치 연동 API, 데이터 저장·실패 처리, 성능 측정과 검증을 소개합니다.

- **Projects**에서 두 프로젝트의 업무와 주요 사례를 볼 수 있습니다.
- **Engineering Cases**에서 API·실시간 통신, 데이터 저장, 장치 제어, 파일 전송, 운영 사례를 확인할 수 있습니다.

이 저장소를 내려받아 브라우저에서 [index.html](index.html)을 열면 사이트를 볼 수 있습니다. 스타일, 스크립트, 이미지, 글꼴은 [assets](assets)에 있습니다.
